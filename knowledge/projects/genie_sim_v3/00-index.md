## `未提及` 清单（**别在这些方向上浪费时间找答案**）

主文档已 grep 确认以下项在论文、代码、官方文档中均无证据：

- **物理**：重力向量未显式 author（用引擎默认 −9.81 −Z）· PhysX 求解器细节（迭代次数 / solver type / CCD / GPU pipeline）未显式设置 · **无确定性保证**（无 seed 固定、无跨运行 bit-wise 复现声明）
- **渲染**：OVRtx 路径上无任何 AA / denoiser / DLSS / TAA；路径追踪噪声靠 `rt_subframes`（默认 8）累积压制
- **域随机化缺失**：相机**内参**随机化 · 质量/摩擦/恢复系数随机化 · 延迟/抖动随机化 · 执行器噪声与增益随机化 · 重力/空气阻力随机化
- **传感器缺失**：深度噪声 · IMU 噪声 · LiDAR 噪声 · 实例分割 · 触觉传感器 · 独立 6 轴力/力矩传感器 · 立体基线双目校正（`p=[K|0]`, `r=I`）· 卷帘快门 / 曝光 / 运动模糊 · 跨相机硬同步触发 · 通信延迟建模
- **安装**：内存 / 磁盘要求
- **官方文档站**：`agibot-world.com/sim-evaluation/docs/#/v3` 是纯 JS SPA，抓取仅得标题，正文无法获取

完整缺口表见 §2.4.16（行 799）与 §8.1（行 1457）。
