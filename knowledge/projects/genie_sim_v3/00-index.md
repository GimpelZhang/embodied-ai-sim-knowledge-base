## `ai_knowledge.md` 章节地图（经验层 · 372 行）

一次真实复现（2026-05-24 → 06-06，五阶段）的复盘。**编号 `P01`–`P18`（问题）／`D1`–`D10`（决策）／`L1`–`L8`（教训）永久稳定，可直接引用。**

**摘要** —— 五阶段（环境搭建 → LLM 场景生成 → 3DGS 重建 → USD 物理注入 → 资产规范化）的实际达成：Stage 1 官方任务 90%（9/10）；Stage 2 生成流水线 6/6 通但策略得分 0/6（判定为 π0 的 OOD 泛化失败，非缺陷）；Stage 3 重建 PSNR 22.6–24.5 dB **未达自设 >25 dB 线**，USD 物理注入基础设施 6/6 通过；深化实现验证门 G1–G4 通过、G5 两次 DEFERRED。**三条最高价值结论**：① Isaac Sim 5.1 要求**硬件 RT cores（CC ≥ 7.5）**，V100 的 7.0 会让渲染器静默失败、任务永久挂起，软件光追一概被拒；② **CUDA 架构错配会伪装成显存问题**（极小张量报 OOM、请求 56 GiB），换卡后必须重编译所有扩展；③ **"日志在刷 ≠ 任务在跑"**，须用 GPU 利用率／端口 ESTABLISHED／日志明确标记作独立判据。另贯穿两套方法论：「陷阱排序」与 **G1–G5 带数值阈值的客观门禁**。诚实复盘：某阶段 8–10 小时里仅约 2.5 小时是有效工作。

## `未提及` 清单（**别在这些方向上浪费时间找答案**）

主文档已 grep 确认以下项在论文、代码、官方文档中均无证据：

- **物理**：重力向量未显式 author（用引擎默认 −9.81 −Z）· PhysX 求解器细节（迭代次数 / solver type / CCD / GPU pipeline）未显式设置 · **无确定性保证**（无 seed 固定、无跨运行 bit-wise 复现声明）
- **渲染**：OVRtx 路径上无任何 AA / denoiser / DLSS / TAA；路径追踪噪声靠 `rt_subframes`（默认 8）累积压制
- **域随机化缺失**：相机**内参**随机化 · 质量/摩擦/恢复系数随机化 · 延迟/抖动随机化 · 执行器噪声与增益随机化 · 重力/空气阻力随机化
- **传感器缺失**：深度噪声 · IMU 噪声 · LiDAR 噪声 · 实例分割 · 触觉传感器 · 独立 6 轴力/力矩传感器 · 立体基线双目校正（`p=[K|0]`, `r=I`）· 卷帘快门 / 曝光 / 运动模糊 · 跨相机硬同步触发 · 通信延迟建模
- **安装**：内存 / 磁盘要求
- **官方文档站**：`agibot-world.com/sim-evaluation/docs/#/v3` 是纯 JS SPA，抓取仅得标题，正文无法获取

完整缺口表见 §2.4.16（行 799）与 §8.1（行 1477）。
